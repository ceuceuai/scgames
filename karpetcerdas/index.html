Belajar Tidak Harus Terasa Seperti Ujian

Karpet Cerdas Terbang menggabungkan kuis edukasi, game endless runner, progres pemain, dan pengalaman visual yang ramah anak.

Masalah Game Kuis Biasa

  • ×Anak cepat bosan karena hanya menekan tombol jawaban.
  • ×Jawaban salah hanya diberi tanda tanpa pembahasan.
  • ×Tidak ada progres, koleksi, atau tantangan harian.
  • ×Pengelola harus mengedit kode untuk menambah soal.

Solusi Karpet Cerdas

  • ✓Pemain bergerak aktif memilih awan jawaban di tiga jalur.
  • ✓Setiap jawaban salah disertai jawaban benar dan Pintar-Poin.
  • ✓Ada level, skin karpet, badge, misi harian, dan leaderboard.
  • ✓Bank soal dikelola dengan mudah melalui Google Sheets.

Pertanyaan yang Sering Ditanyakan

Ubah bagian ini sesuai lisensi, metode pengiriman, dan layanan bantuan yang kamu berikan.

Apakah game membutuhkan VPS atau hosting berbayar?
Tidak harus. Game dirancang menggunakan Google Apps Script sebagai backend dan Google Sheets sebagai database. Penggunaan tetap mengikuti kuota dan kebijakan layanan Google.
Apakah soal dapat diganti tanpa mengedit kode?
Ya. Soal, kategori, level, pilihan jawaban, bonus, dan pembahasan dapat dikelola melalui Google Sheets.
Apakah judul dan logo game dapat diganti?
Bisa. Sistem mendukung pengaturan judul, logo, nama developer, aturan poin, syarat naik level, teks share, dan tautan dari konfigurasi spreadsheet.
Apakah game bisa dimainkan melalui HP?
Ya. Antarmuka game dibuat responsif dan kontrolnya mendukung sentuhan, geser, ketuk, serta keyboard untuk desktop.
Apakah suara Guru Virtual menggunakan layanan AI berbayar?
Tidak. Fitur suara menggunakan Web Speech API bawaan browser. Ketersediaan dan jenis suara dapat berbeda pada setiap perangkat atau browser.
Apakah source code boleh dijual ulang?
Ketentuan penggunaan, modifikasi, proyek klien, dan penjualan ulang harus disesuaikan dengan lisensi yang kamu tetapkan sebagai penjual.
