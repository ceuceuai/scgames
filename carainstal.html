Panduan Deploy Games Whitelabel

Langkah demi langkah mengatur database Google Sheets, melakukan deploy Apps Script, hingga mempublikasikan game di Vercel.

1

Persiapan Database (Google Sheets)

Google Sheets akan bertindak sebagai database gratis untuk menyimpan skor Leaderboard dan mengatur konfigurasi Whitelabel game Anda.

  • Buka akun Google Drive Anda.
  • Buat Spreadsheet kosong baru, atau Buat Salinan (Make a copy) dari file master Google Sheets yang telah disediakan.
  • Beri nama file tersebut, misalnya: Database Galactic Shooter.
  • Di menu bagian atas Google Sheets, klik Ekstensi > Apps Script.
2

Inisialisasi Database (Wajib)

Langkah ini diperlukan untuk membuat tab Leaderboard dan Settings secara otomatis di Spreadsheet Anda.

Penting!

Pastikan kode Code.gs dan Index.html sudah ada di editor Apps Script Anda sebelum melanjutkan.

  1. Di halaman editor Apps Script, perhatikan menu bar di bagian atas.
  2. Cari dropdown fungsi (biasanya tertulis doGet), lalu ubah menjadi setupSheet.
  3. Klik tombol Jalankan (Run).
  4. Jika muncul popup "Otorisasi Diperlukan" (Authorization Required):
    • Klik Review Permissions.
    • Pilih akun Google Anda.
    • Klik Advanced (Lanjutan) di bagian bawah.
    • Klik Go to... (unsafe).
    • Klik Allow (Izinkan).
  5. Kembali ke Google Sheets Anda. Anda akan melihat dua tab baru muncul di bawah: Leaderboard dan Settings.
3

Deploy Web App (Apps Script)

Sekarang kita akan mengaktifkan game agar bisa diakses melalui internet.

  1. Di editor Apps Script, klik tombol biru Terapkan (Deploy) di pojok kanan atas.
  2. Pilih Deployment baru (New deployment).
  3. Klik ikon roda gigi (⚙️) di sebelah "Pilih jenis", lalu centang Aplikasi Web (Web app).
  4. Isi konfigurasi dengan TEPAT seperti berikut:
    • Deskripsi: Galactic Shooter V1 (Bebas)
    • Jalankan sebagai (Execute as): Saya / Me
    • Siapa yang memiliki akses (Who has access): Semua Orang / Anyone *Jangan pilih yang lain!
  5. Klik Terapkan (Deploy).
  6. Akan muncul URL panjang berakhiran /exec. Salin (Copy) URL tersebut. Kita akan menggunakannya di langkah selanjutnya.
4

Integrasi iFrame & Deploy ke Vercel

Agar game memiliki link yang rapi (bisa custom domain) dan berjalan fullscreen (penuh di layar HP), kita akan membungkusnya menggunakan Vercel.

  1. Buat folder baru di komputer Anda (misal: game-whitelabel).
  2. Buat file bernama index.html di dalam folder tersebut.
  3. Buka file tersebut menggunakan Text Editor (Notepad, VS Code, dll), lalu masukkan kode Wrapper (pembungkus) yang telah disediakan.
  4. Cari baris kode <iframe class="game-frame" src="..."> di dalam file tersebut.
  5. Ganti tulisan di dalam src="" dengan URL Apps Script yang Anda salin pada Langkah 3.
    <!-- CONTOH CARA MENGGANTI LINK -->
    <iframe
      class="game-frame"
      src="https://script.google.com/macros/s/AKfycb.../exec"
      allowfullscreen="true"
      scrolling="no">
    </iframe>
  6. Simpan (Save) file index.html tersebut.
  7. Login ke Vercel.com.
  8. Tarik dan lepaskan (Drag & Drop) folder game-whitelabel Anda langsung ke dashboard Vercel untuk melakukan deploy.
  9. Selesai! Vercel akan memberikan link publik yang siap dimainkan dan dibagikan.
5

Mengatur Settingan Whitelabel

Cara mengubah nama game, nama developer, dan link tujuan tanpa harus menyentuh kode HTML:

  • Buka kembali file Google Sheets Anda.
  • Klik tab Settings yang ada di bagian bawah lembar kerja.
  • Ubah teks yang berada di kolom B (Value) sesuai keinginan Anda.
  • Refresh (Muat Ulang) halaman game Anda di browser. Teks dan Link akan otomatis berubah mengikuti data terbaru di Google Sheets!
